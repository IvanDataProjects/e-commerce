# 🛒 E-commerce Backend API

API REST completa de un sistema de e-commerce desarrollada con **Spring Boot**, enfocada en arquitectura backend, seguridad y buenas prácticas en entornos de producción.

---

## 🚀 Descripción del proyecto

Este proyecto simula un backend real de e-commerce, incluyendo gestión de usuarios y pedidos, autenticación segura y evolución hacia una arquitectura distribuida basada en microservicios.

Incluye desde un monolito inicial hasta conceptos de comunicación entre servicios y mensajería.

---

## 🧱 Arquitectura y evolución

- API REST con Spring Boot
- Arquitectura basada en capas (Controller, Service, Repository)
- Uso de DTOs para separación de responsabilidades
- Evolución hacia microservicios
- Comunicación entre servicios mediante REST
- Introducción a mensajería con Kafka / RabbitMQ (conceptual o básico)

---

## 🔐 Seguridad

- Autenticación basada en **JWT**
- Login de usuario con generación de token
- Validación de token en endpoints protegidos
- Control de acceso a recursos

---

## 📦 Funcionalidades principales

- CRUD de usuarios
- CRUD de pedidos
- Relación entre usuarios y pedidos
- Validación de datos
- Gestión de lógica de negocio en servicios

---

## 🧪 Testing

- Tests unitarios con **JUnit**
- Mocking con **Mockito**
- Tests de servicios y controladores

---

## 🐳 DevOps / Despliegue

- Dockerfile para contenerización de la aplicación
- Ejecución del backend en contenedor
- Preparado para entornos de despliegue básicos

---

## 🛠️ Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Security
- JWT
- JPA / Hibernate
- MySQL
- JUnit / Mockito
- Docker
- Maven

---

## 📌 Aprendizajes clave

- Diseño de APIs REST bien estructuradas
- Implementación de seguridad con JWT
- Separación de responsabilidades (arquitectura limpia)
- Testing de lógica de negocio
- Introducción a microservicios y mensajería
- Contenerización de aplicaciones con Docker
